# Session log - agent first-pass classification of all 29 papers (4 Nov 2026, ~15:30)

Task (owner request): do the same agent-mode classification done for the 65 questions of 2026 CS-1
for ALL 2011-2026 papers; verify API connectivity path (without keys); improve UI; test and review all.

## What was done
1. Read every question of the 28 unclassified papers (1,820 questions) from the staging DB.
2. Wrote one TSV of labels per paper (65 rows each) as an agent reading each question - same method
   as the 65 of 2026 CS-1. 2013 S2/S3/S4 are shuffles of the SAME 65 questions as 2013 S1 (official
   multi-session year); labels were generated by normalized-text matching plus manual patches for the
   shared common-data stems (Q48/49 PDS.C, Q50/51 COA.ISA, Q52/53 DB.NF, Q54/55 OS.MEM) and OCR variants.
3. `scripts/apply_agent_classifications.py` wrote them: model=claude-agent-manual-v2,
   prompt_version=agent-v2, provenance=inferred, status=suggested (1,377) or flagged (508).
   It refuses taxonomy-invalid ids (deprecated TOC.PUMP caught and fixed to TOC.RCFL), refuses to
   touch any question with an existing row (the 65 v1 labels untouched), flags low-confidence rows
   into review_events (508 new).
4. Offline keyword heuristic (`src/classification/heuristic.py`, CLI `classify-local`) built as a
   second opinion: agrees with the agent topic on 60% of all 1,885; on the 65 v1 labels 45/65 (69%).
5. UI: Pipeline Status now breaks unverified suggestions down by model; analyze/export default
   year range starts at 2011 (29 papers visible by default).
6. ANALYSIS.md + exports/ regenerated from staging. Tests: 191 passed, 3 skipped.

## Honesty notes
- Nothing is human-verified. Every label is a machine/agent suggestion (provenance=inferred).
- Software-engineering questions (testing, COCOMO, SRS, cohesion/coupling) have no taxonomy topic;
  they carry PDS.C at 0.3-0.35 confidence with a flag. Taxonomy extension is a human decision.
- No LLM API calls were made; no external disclosure. The API path stays gated on the owner's key
  and explicit approval.
